# java-racingcar-precourse

## 기능 요구 사항
- 입력
    - 자동차 이름 입력 요청 및 처리
    - 시도할 횟수 입력 요청 및 처리

- 유효성 검사 및 파싱
  - 자동차 이름 유효성 검사 및 파싱 (5자 이하, 쉼표 구분)
  - 시도 횟수 유효성 검사 및 파싱 (0 이상 정수)
  - 잘못된 입력 시 IllegalArgumentException 발생

- 핵심 로직
  - 0-9 사이 랜덤 숫자 생성 유틸리티
  - 자동차 전진/멈춤
  - 자동차 경주 단일 턴 실행
  - 자동차 경주 우승자 판별

- 뷰
  - 턴별 실행 결과(자동차 위치) 출력
  - 최종 우승자 출력

- 앱
  - 전체 게임 흐름(입력 -> 검증 -> 게임 실행 -> 결과 출력) 제어
